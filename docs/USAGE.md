# 使用与常见问题

[返回首页](../README.md) · [安装](INSTALL.md)

## 搜索

打开 B站或小红书首页，在入口选择平台、输入关键词并回车。结果页是原站页面，视频和笔记仍由原站提供。插件接管的是首页入口，并不是离线搜索或另一套内容服务。

## 收藏直达

入口搜索框下方的收藏按钮用于打开已保存目标。第一次使用会让你设置：

1. 选择「去 B站 / 小红书找收藏夹」。
2. 在打开的临时设置页中登录自己的账号，进入需要的收藏夹。
3. 在插件浮窗中点击「保存此页」。

设置限时 3 分钟，超时后可重新开启。浮窗挡住按钮时，可以拖动把手或收起；它不会把整个原站页面向下推。再次点击找收藏会激活已有设置页。

手工地址需要是具体收藏夹、列表或合集，普通视频、搜索页、B站空间首页不能作为收藏入口。小红书允许保存个人主页并自动补收藏参数；请选择自己的主页，是否显示收藏由原站控制。不要把含个人访问参数的完整 URL 发到公开 Issue。

## 登录

登录使用原站表单。小红书入口的「去登录」会先建立按标签页生效的限时权限，默认仍隐藏推荐；若登录框未打开，可以重试或使用最多 5 分钟的原站备用登录窗口。刷新不会延长原截止时间。完成或取消后会撤销临时权限。

插件不接收账号密码，不绕过验证码、平台风控或访问权限。扫码 / 验证码需本人操作。

## 三种风格与语言

点工具栏图标，或入口右上角「风格」，选择知止、你学不学或同桌。切换时已有收藏和计时共用。

同桌中的朋友名字、留言都可以自行填写，点击保存。名字最多 24 字符、留言最多 160 字符，可换行。不随机，也不自动改写。界面语言可切换为中 / EN，留言仍保留原文。

## 休息

点击入口右下角「休息一下」，确认后填写 1–180 分钟。休息状态按平台共享，首页临时放行并显示倒计时。到期或主动结束后，首页回到入口；已有搜索、视频和收藏页保留，计时器移除。

系统睡眠、浏览器关闭或 API 故障可能让回调延迟，恢复后会按原截止时间处理。若结束失败，界面保留状态并提示错误，可稍后重试。

## 常见问题

**收藏保存按钮是灰色的？** 先进入具体收藏页；B站首页不能保存，小红书可进入自己的个人主页。确认三分钟设置窗口仍有效。

**换了电脑，原来的收藏不见了？** 设置保存在当前浏览器扩展本地，没有开发者云同步。不同浏览器、配置文件、安装目录可能是不同的扩展实例。

**想临时恢复推荐？** 使用限时休息，或在扩展管理页停用插件后刷新。

**搜索后白屏或登录没出现？** 刷新页面，检查原站是否能正常访问，并确认没有同时启用多个接管首页的插件。还可尝试原站备用登录。若持续出现，请提供浏览器版本、平台、触发步骤及去除隐私后的截图。

**能用于手机 / 其他浏览器吗？** 手机 App 不支持；其他 Chromium 浏览器未逐个验证。当前主要面向桌面 Chrome / Edge。

**是网站官方插件吗？** 不是。本项目与 B站、小红书没有隶属或背书关系；网站内容及账号服务由各平台提供。
